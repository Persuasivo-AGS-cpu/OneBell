# OneBell v2

App personal de entrenamiento con una sola kettlebell. Estilo "Brasa".

- `src/screens/` una pantalla por archivo
- `src/data/catalog.json` catálogo de 98 ejercicios (89 del catálogo + 9 calentamientos de la v1)
- `src/assets/ex/` fotos de la v1 comprimidas
- `src/lib/` sesión, catálogo y guardado

Comandos: `npm install`, `npm run dev`, `npm run build`, `npm test`. Vercel compila con `npm run build` y publica `dist/`.

La v1 se conserva en la rama `v1`.
